# Product Requirements Document

## Core Features

### 1. Website Scanner
- SEO, LLMO, AEO, GEO analysis
- Legal compliance
- Accessibility
- Performance
- Security
- UX review
- AI review

### 2. Lead System
- Email verification required
- Leads stored in CRM
- Source tracking

### 3. AI Website Prototype Builder
- Conversational AI
- Generates website preview
- Editable output

### 4. Monitoring System
- Uptime tracking
- SSL monitoring
- Domain monitoring
- Performance tracking

### 5. Dashboard
- Per-site analytics
- Scores
- Reports
- Trends

### 6. AI Chat Assistant
- Converts visitors into leads
- Answers questions
- Explains services

---

## Scoring System

Each category: 0–100
Overall score: weighted average

Weights:
- SEO 20%
- Performance 20%
- Security 20%
- Accessibility 15%
- Legal 15%
- UX 10%
