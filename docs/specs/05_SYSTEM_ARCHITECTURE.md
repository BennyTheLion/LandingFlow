# System Architecture

- React / Next.js
- Tailwind or Bootstrap
- PWA support
- RTL support

## Backend
- Node.js or PHP
- REST API
- Queue system (Redis)

- Redis cache

- Claude API (optional)
- Internal prompt engine

- Performance scanner
- Legal checker
- Accessibility scanner
