# Non Functional Requirements

## Performance
- Page load < 2s
- API response < 300ms (cached)
- Scan execution < 60s for average site

## Scalability
- Multi-tenant architecture
- Support 10,000+ sites per tenant

## Availability
- 99.9% uptime target

## Security
- OWASP compliance
- Encryption at rest and in transit

## Maintainability
- Modular architecture
- Clean API separation

## Usability
- Mobile-first design
- RTL support
- WCAG accessibility compliance

## Observability
- Full logging
- Error tracking
- Performance metrics
