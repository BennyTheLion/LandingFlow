# Functional Requirements

## Website Scanner

System must allow users to:
- Submit website URL
- Crawl website pages
- Run analysis modules:
  - SEO
  - Legal
  - Accessibility
  - Performance
  - Security
  - UX
  - AI Review

## Email Verification Flow

- User must verify email before:
  - Running scan
  - Viewing full report
  - Generating prototype

## Lead System

- Store all emails in leads table
- Track source (organic, ads, referral)
- Store scan results linked to lead

## AI Chat Assistant

- Answer visitor questions
- Guide to conversion
- Trigger lead capture

## Prototype Builder

- Generate website mockup from conversation
- Allow preview rendering
