# UI/UX Guidelines

## Design System
- Clean SaaS UI
- Minimal cards layout
- Data-driven dashboards

## Mobile First
- Responsive design required
- Bottom navigation in mobile
- Touch optimized

## Colors
- Primary: Blue / Indigo
- Success: Green
- Warning: Yellow
- Error: Red

## Components
- Cards
- Charts
- Tables (desktop only)
- Modals
- Stepper flows

## UX Principles
- Reduce friction
- One CTA per screen
- Progress indicators
- Instant feedback

## Accessibility
- WCAG AA minimum
- Keyboard navigation
- Screen reader support
